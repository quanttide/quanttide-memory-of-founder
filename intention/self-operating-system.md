# 作者对平台的规划：自我操作系统

记录于 2026-08-15（基于 qtfounder 全貌重建，经作者确认）。

## 定位

不是"创作管理工具"，而是把**创作、记忆、情绪、表达**整合成一个闭环的**个人认知平台**——让"自己"成为可观测、可管理的对象。

## 平台层次

| 层 | 模块 | 功能 |
| --- | --- | --- |
| 数据层 | fiction + memory | 第二大脑资产：创作产出 + 记忆（roadmap 方向 / context 方法 / journal 事实） |
| 观察层 | site + studio | **创作现场**：时间线 / 矩阵 / 改稿轨迹——把创作过程变成可看的"现场" |
| 服务层 | provider | 数据统一出口（API） |
| 分析层 | cli health | **情绪维度量化**（git 历史 + LLM：valence / arousal / warning_signs） |

## 深层意图

### 1. 叙事疗法平台化

小说是"把不敢说的，变成可以说的"的重构出口——平台让这个过程**可观测、可管理**（改稿轨迹 = 治疗轨迹）。

### 2. 情绪闭环

记录情绪（cli）→ 写入创作（fiction）→ 观察轨迹（studio）→ 反哺现实（"反过来启发我在现实世界里积极行动"）。

### 3. 元目标

"建立描述现实状况和未来想象的叙事习惯"——平台是培养这个习惯的**外化工具**。

### 4. 表达即品牌

"创作现场"对外展示 = 从展示作品到展示**创作过程**——过程本身成为个人品牌（"小说作为公司宣传和品牌故事"）。

## 与公司治理思想同构

这是"公司活过创始人 / 知识资产化"的**个人版本**：

```
公司层：决议档案 → 治理视图（qtadmin-delib）
个人层：创作/记忆/情绪 → 创作现场（qtfounder）
```

——都是"把隐性的东西显性化、让系统自运行"。
