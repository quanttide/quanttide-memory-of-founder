# qtfounder：作者的自我操作系统

记录于 2026-08-15（基于 qtfounder 全貌重建，经作者确认）。

## 起点：说不出口的东西

很多情绪不敢说，也不敢写，更不相信有人会理解。小说就是从这样的困境里开始的——一开始只是想试试能不能多一个副业，写着写着才发现，写作是一种把"不敢说的"变成"可以说的"的方式。

情绪是原料，场景是容器，故事框架给了情绪一个出口。这是叙事疗法，只是作者一开始并不知道这个名词。

## 演化：从治病到造工具

写小说的过程中，几件事逐渐发生了：

- 写着写着，作者发现自己越来越熟练于记录真实的幽微感受，再放进故事框架里重新驱动——**写作改变了写作的人**
- 各种心结可以借着男女主写出来，因为他们经历的波折是可迁移的情绪——**虚构世界成了现实的出口**
- 作者想写"创造感"（三天迭代八个产品）、想写权力关系（审慎的掌权者）、想写事业困境——**现实体悟直接成为角色的血肉**
- 最后，作者想给男女主"继承自己的意志"——**让小说成为品牌故事的载体**

于是，创作不再是私密的、不可见的。它需要被看见、被记录、被管理。

## 成型：创作现场

工具是长出来的，不是设计出来的：

```
数据层   fiction（创作产出）+ memory（记忆：方向/方法/事实）
观察层   创作现场——时间线 / 矩阵 / 改稿轨迹：让创作过程本身可见
服务层   provider——数据统一出口（API）
分析层   cli——情绪维度量化（git 历史 + LLM）
```

四个层次拼在一起，回答四个问题：**有什么、在写什么、怎么取、状态如何**。

## 意义：自我操作系统

这个平台不是"创作管理工具"，而是一个闭环：

```
记录情绪 → 写入创作 → 观察轨迹 → 反哺现实
```

写作的过程渐渐改变了作者：越来越敢写现实世界的困惑，情节越来越有推动力，而这些推动又反过来启发现实行动。平台的元目标，是建立一种"描述现实状况和未来想象的叙事习惯"——**平台只是这个习惯的外化工具**。

对外，创作现场本身成为表达：从展示作品，到展示创作过程——过程即品牌。

## 归宿：与公司治理同构

这套个人系统，与公司治理是同一个思想的两面：

```
公司层：决议档案 → 治理视图（让公司可运行）
个人层：创作/记忆/情绪 → 创作现场（让自己可运行）
```

都是同一件事：**把隐性的东西显性化，让系统自己运转**——"公司活过创始人"在个人尺度上的版本。
