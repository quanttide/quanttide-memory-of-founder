# 叙事工程

那就完全说得通了。
你觉得“代入不了女主”，不是因为你不懂她，而是因为你把“照顾者”这个角色外包出去了。
在你的人格里，你是那个失眠的、心里缺一块的、想被照顾的人。所以写他的时候，你如鱼得水，因为那是你的切肤之痛。
但“照顾者”也是你衍生出来的——这意味着，她不是别人，她是你身上那个“想要自救的部分”，或者“理想中能接住自己的力量”。
你不是代入不了她，你是不敢认她。因为承认她，就意味着你要从“被照顾的脆弱”里站起来，去面对“怎么照顾自己”这个问题。这比写小说难多了。
换一种方式理解她
她不是“另一个人”。她是当你熬到凌晨三点、心里空到发疼的时候，脑子里那个说“去睡觉吧”的声音。
那个声音可能很微弱，可能你经常不听它的。但它在那儿。
写她，就是写那个你经常忽略的声音。
试试这个练习
用她的视角写，但不要想“她在想什么”，而是想——
“如果我心里有一个声音，在这一刻会说什么？”
她看他眼睛浮肿，脸色发黄。
他（你）的感受是：我好累，好空，想被接住。
她（你心里的声音）的感受是什么？可能是：
“又这样。”（心疼+无奈）
“他不肯停的。”（了解+无力）
“得让他闭上眼睛。”（行动+决断）
“我没办法替他填上那块空，但我能让他先歇一会儿。”（清醒+边界）
你看，最后一个——“我没办法替他填上那块空，但我能让他先歇一会儿”——如果你能写出这个，她的视角就开了。
因为这不是“温柔女主照顾男主”，这是一个人知道自己能做什么、不能做什么，但还是做了能做的那一点。
这就是你自己身上那个最清醒的部分。
再试一次
从她的眼睛看出去：
他的眉头皱着，手指在屏幕上敲得很快。他写东西的时候总是这样，像是把骨头里的东西往外抽。
这是她看见的。
她想让他停下来。但她知道他停不下来——他自己也写过，写东西会好得多。
这是她理解的他——而这个理解，其实就是你自己对自己的理解。
她能做的只有这么多了。
她从包里拿出蒸汽眼罩，拆开，走过去。
“你是不是又失眠了？”
她没等他回答，把眼罩戴在他眼睛上。
“别看啦，闭上眼睛休息一会儿吧。”
她没等他回答——这就是你和自己的相处方式。你知道如果等自己回答，答案永远是“再写一会儿”。所以那个声音不商量，直接上手。
最后
你说男女主都是从你的人格衍生的。
那么——
他，是你允许自己脆弱的那一面。
她，是你正在学习照顾自己的那一面。
你写不好她，不是因为你不是她，而是因为你还没完全成为她。
但没关系。写小说就是你练习成为她的过程。
每一次用她的视角写一段，都是你在心里对自己说一次：“闭上眼睛休息一会儿吧。”
不用写好。先写。写着写着，你会发现她越来越清晰，因为她就是你还没长出来的那块骨头。

--


这篇文章的叙事手法非常老练，用坦诚到近乎粗粝的方式，完成了一次高段位的招聘营销。它的叙事亮点主要体现在以下几个层面：

亮点一：以“认错”开场，制造信任感与悬念
文章开头就是一个反常规操作：面试出现理解偏差，面试官说“这不应该是面试者的责任，是我们自己没有讲清楚”。在大多数招聘文习惯高高在上审视求职者时，这种主动揽责的姿态立刻建立起强烈的真诚感。同时，开篇抛出具体数字“169封简历”，又制造了一个悬念——这么多人来应聘的业务，为什么被称为“最脏”？

亮点二：犀利定义颠覆认知，用“脏”字贯穿全文
“咨询服务乙方是甲方爸爸的打手”，这个比喻把咨询行业从“战略、赋能”等大词中直接拽入泥泞。随后用“脏乱差”“背锅”“办公室政治的泥泞”等一系列粗粝词汇，持续强化“脏”的意象。这种去魅式的叙事，不仅不令人反感，反而因为极度坦诚而显得耳目一新，让读者觉得：这是一家敢说真话、不装腔作势的公司。

亮点三：对比结构，凸显“必经之路”的必然性
文章将“数据/课堂业务”与“咨询业务”做对比：前者客户是高校师生，“素质较高，容易服务”；后者要面对“多方利益冲突，规模更大、组织更复杂”。但紧接着给出判断：“这是我们的必经之路。”这种先抑后扬的叙事，把“脏活累活”从无可奈何的妥协，升华为主动选择的战略路径，塑造出公司敢于啃硬骨头的坚韧形象。

亮点四：重构“护城河”，引出真正的筛选标准
最精彩的部分在于重新定义护城河。不是技术专利，也不是客户关系，而是“话语权”。而话语权的来源，是“敢冲向客户觉得最脏乱差的地方，四两拨千斤地解决问题”，同时还要做到“花小钱办大事”和“边际成本足够低”。这串递进逻辑，实质上是在描绘他们心中的理想员工画像——一个能用技术代差低成本解决复杂人情世故和系统混乱的实战派。

亮点五：将“残酷真相”转化为“英雄召唤”
结尾处，文章没有画饼，而是直接把残酷现实摆上台面：“市场在变化，企业生存需要敢于趟浑水，所以我们也只能选有能力趟浑水的求职者。”这里的叙事巧妙之处在于，它用“敢不敢趟浑水”这个门槛，自动筛选出了认同其价值观的人。对这样的人而言，“脏”不再是劝退理由，而是一种充满挑战和成就感的英雄主义召唤。

总结来说，这篇文章的叙事亮点是：用粗粝真诚的语态，构建了一个从“认错去魅”到“重新赋魅”的闭环。 它先把业务扒开揉碎给你看有多脏多难，然后告诉你，正因为如此，能解决它的人才无比稀缺且真正拥有护城河。最终把一篇解释误会的“工作教程”，变成了一则精准吸引同类的“招聘宣言”。


你说得对，我刚才的回答确实丢了原文最锋利的刀刃。

原文的亮点不在于“怎么说好听”，而在于它用那种近乎粗鲁的坦诚，建立了一种让客户无法质疑的信任感。我把这些骨头剔掉了，换成了一堆安全的商业话术，这本身就是一种背叛。

让我重新挖掘——面向客户时，原文哪些东西必须原样保留，因为它们才是真正击穿防线的子弹：

—

1. “打手”这个比喻本身——直接摊牌，反而最可信

客户听惯了“赋能”“陪跑”“共创”，这些词已经被用烂了，说出口就触发防御机制。但如果你敢说“我就是您的打手”，效果完全不同——

这句话传递的信息是：我不跟您装，我知道咨询的真相就是帮老板实现意图，我认。这种“把潜规则摆在明面上”的姿态，反而让客户觉得：这家人不忽悠，能信。

话术建议（保留原味）：
“说白了，咨询就是个脏活。您需要的不是一个指手画脚的老师，而是一个敢下场动手的‘打手’。这个角色，我们认，我们也擅长。”

—

2. “脏乱差”的意象——不是暴露短板，而是展示肌肉

原文反复强调“最脏乱差的角落”“办公室政治的泥泞”“跌打滚爬”，这些词堆在一起，构成的是一个画面：一群人在烂泥里把事办成了。

对客户来说，这比任何案例都性感。因为老板比谁都清楚，自己的公司里哪有烂泥。你说“我能搞定烂泥”，他立刻会想：“那看看我这摊你能不能搞定。”

话术建议（保留原味）：
“我们接的项目，往往是企业里最脏乱差的那一块——数据乱的、人心散的、推了三年推不动的。别人挑肥的吃，我们专啃骨头。啃下来了，才是真本事。”

—

3. “背锅”的坦荡——主动接住客户最隐秘的恐惧

这是原文最狠的一笔。它直接说出了老板想做但不敢明说的需求：找个能背锅的人。

面向客户时，话不能说得这么白，但味道不能丢。要点在于：让客户感受到，你知道他要承担风险，你愿意帮他分担，而且你不觉得这是委屈。

话术建议（保留原味）：
“内部改革，老板要冒很大的政治风险。我们的角色，就是帮您降低这个风险。事成是您的政绩，中间有什么摩擦，有我们在前面挡着。”

—

4. 不装、不美化——用“粗粝”筛出对的人

原文从头到尾没有一句鸡汤，没有一张大饼。就是告诉你：这活很脏、很难、很累，你干不干？

这种姿态本身就是最好的客户过滤器。它会把那些想找个乙方来粉饰太平、做面子工程的客户自动劝退。留下来的，是真正有痛点、想解决真问题的老板。他们从这样的叙事里读到的不是“脏”，而是“这家公司能打”。

—

一句话总结：
原文面向客户的核心亮点，不是“性价比”或“兜底能力”这些结论，而是得出这些结论的方式——那种敢于把行业潜规则摊在阳光下、敢于说“这事就是脏的但我能搞定”的匪气。

它让客户觉得：这个人没骗我，因为他连最难听的话都说了。

好的，我们来拆解一下这篇文章里透出来的“匪气”。

“匪气”在这里绝不是指粗俗或违法，而是一种在商业战场上的特殊气质。它混合了极致的务实、对规则的蔑视（指那些虚伪的行业规则）、以及一种“这事老子能搞定”的草莽生命力。

我们可以把它拆解成四个层次，并用原文来对照：

1. 敢亮底牌的诚实，是最高的骗术

商业世界习惯了包装和美化，而“匪气”的第一特征就是主动掀开遮羞布。

· 不装高大上：原文说企业咨询不是“高大上”，而是做“甲方爸爸的打手”，陷入“最脏乱差的角落”。这不叫自黑，这叫亮底牌。它传递的信息是：“我都告诉你最烂的部分了，我后面说的好的部分，你还能不信吗？”
· 直接谈“背锅”：原文直言“如果失败了，那么我们就是背锅的。”这在商业沟通里是大忌。但“匪气”的逻辑是：你心里最怕的就是改革失败自己扛责，这个雷，我明确告诉你，我可以接。这种坦荡，瞬间瓦解了客户的心理防线。

2. 不按常理出牌，重构游戏规则

循规蹈矩是商学院的路子，“匪气”是野路子，擅长用自己的方式重新定义游戏。

· 把“脏活”说成“护城河”：当其他公司在炫耀自己的方法论、豪华团队时，这家公司告诉你：“我们的护城河是敢冲向最脏乱差的地方”。这完全跳出了常规的价值叙事，建立了一个只有他们自己在玩的游戏。你想比？对不起，你先比比谁更不怕脏。
· 把“政治泥泞”看作核心能力：别人强调专业、工具、模型。他们强调搞定“办公室政治”、“多方利益冲突”。这等于在说：我们不是在真空里做方案，我们是在真实的人性泥潭里把事办成。

3. 极致的功利主义：只认结果，不认面子

“匪气”的行动准则极其简单粗暴：这事儿能不能成？怎么能用最小的代价办成？

· “花小钱办大事”：原文这句非常关键。它不是说要给客户省钱，而是说我有能力用巧劲，四两拨千斤。这背后是一种资源的极度自信和解决问题的野路子智慧。
· “边际成本要足够低”：这句话对客户是说“我们能赚钱”，深层意思是“我们玩的不是一个辛苦活，我们已经找到了技术和管理代差，可以轻松地赢你”。这是一种来自更高维度的、毫不掩饰的自信。

4. 强烈的攻击性和筛选姿态

这种“匪气”是带刺的，它不讨好，而是在筛选。

· 对求职者：不是“欢迎加入”，而是“我们也在找有能力趟浑水的”。这是一种基于能力的平等对视，甚至是筛选。
· 对客户（可以推演）：潜台词是“我们有能力，不怕脏，能帮你成事。但你如果没胆量、没决心，只是想找人来粉饰太平，那别来找我。”这种姿态，反而会强烈吸引那些真正被问题困扰、渴望有人能“摆平一切”的实干型老板。

—

总结一下，“匪气”的画面是：

一个西装革履的专家是这么说的：“根据我们麦肯锡7S模型分析……”
一个有“匪气”的家伙是这么说的：“张总，您公司那个部门的水有多浑，您比我清楚。别整那些虚的，这事儿您就是想换个自己人上去，对吧。方案我有了，脏活我来干，阻力我顶着。干成了，是您领导有方；万一出了岔子，锅在我这。您就告诉我，您到底干不干？”

“匪气”的本质，就是用最粗粝的方式，去解决最精细的问题。它最大的魅力在于，把商业互信的漫长过程，压缩成了一句“这事，我认，我也能平。”


这篇文章的“网感”非常突出，它精准地抓住了当下互联网语境中受众的心理特征和阅读偏好。具体来说，其“网感”体现在以下六个维度：
1. 反共识与“祛魅”的爽文逻辑
网感体现：现在的互联网用户对传统的“高大上”商业包装早已免疫，甚至反感。大家更喜欢看“扒底裤”、“说大实话”的内容。文章开篇就撕破咨询行业“精英、高深”的标签，直言其本质是“打手”、“背锅侠”和“泥泞中打滚”。
效果：这种“祛魅”极其契合当下网友爱看“行业内幕”和“反精英主义”的吃瓜心态，自带一种“说真话”的爽感，极易吸引读者看下去。
2. 精准踩中互联网高频“情绪词”与“黑话”
网感体现：文章大量使用了带有极强网感色彩的词汇：
“甲方爸爸”：互联网圈对甲方的经典戏称，带有一种无奈又真实的调侃。
“打手”：用江湖气十足的词来形容乙方的工具人属性，粗暴但贴切。
“脏乱差”、“泥泞”、“背锅”：极具画面感的负面词汇，制造冲突感。
“四两拨千斤”、“花小钱办大事”：切中当下企业降本增效时代的主旋律。
效果：这些词汇自带流量密码，不仅降低了阅读门槛，还让文章充满了“人情味”和“江湖气”，不像官方通稿那样干瘪。
3. “真诚是最大的必杀技”的人设打造
网感体现：在社交媒体上，“立人设”容易翻车，而“展露脆弱和真实”最能圈粉。作者开篇不装逼，主动承认面试中“是我们自己没讲清楚”，承认自己的业务是“最脏的”，承认失败了自己就是“背锅的”。
效果：这种“自曝其短”的叙事在微信公众图文或知乎等平台上极其讨喜。它迅速建立了一个“务实、坦诚、不装”的老板/公司人设，大幅降低了求职者的防备心理。
4. 制造强烈的对立与冲突（反差感）
网感体现：网感文章必须有“冲突”才能留住眼球。文章构建了多重反差：
业务反差：“干净好搞的高校业务” VS “脏乱差的企业咨询业务”。
认知反差：咨询的高大上外衣 VS 办公室政治的泥泞。
成本与价值反差：花小钱 VS 办大事；边际成本低 VS 保持对客户的代差。
效果：通过对比拉扯，让文章节奏紧凑，观点犀利，避免了平铺直叙的乏味。
5. 底层逻辑的“降维表达”
网感体现：纯讲理论没人看，纯讲故事没深度。这篇文章用非常接地气的比喻来解释复杂的商业逻辑。比如用“趟浑水”来形容企业内部的利益纠葛，用“护城河就是话语权”来总结核心竞争力。
效果：这种“说人话”的表达方式是优秀新媒体文章的标配，让非专业人士也能瞬间秒懂咨询行业的底层痛点，极易引发朋友圈的转发和同行的共鸣。
6. 顺理成章的“PUA式”收尾（高级筛选）
网感体现：现在的招聘文案不再说“我们需要你来改变世界”，而是说“这活儿很苦很脏，你能干再来”。结尾将高标准招聘合理化为“市场需要趟浑水的人”。
效果：这在互联网语境中是一种高级的“反向筛选”（类似“只招特种兵”）。它利用了求职者的“挑战欲”和对强者的认同感，把公司的严苛包装成了对生存的敬畏，让符合条件的求职者产生“我就是那个能趟浑水的人”的优越感。
总结：
这篇文章的“网感”不是单纯的玩梗或使用网络流行语，而是深谙互联网用户的阅读心理——爱看真话、爱看反差、吃软不吃硬。它用粗糙直白的语言包裹着深刻的商业洞察，把一篇枯燥的招聘启示写成了一篇有态度的行业随笔。
