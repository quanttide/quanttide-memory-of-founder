## 个人创作系统

基于 5 组实验验证的创作-情绪模型。

### 底层假设

创作不是"倒苦水"，是"开药方"。写什么、怎么写、写到多深，决定情绪走向。

### 选题原则

- 只写转化型母题（害怕但面对、脆弱但被接纳、冲突但沟通）
- 只写补偿型母题（温暖、陪伴、安全感、被理解、小确幸）
- 核心母题：守护、脆弱反差、时间与成长
- 禁忌：不写孤独致死、背叛决裂（会恶化情绪）

### 情绪走向

日记管现实（发生了什么），小说管理想（我想要什么）。
- 每周三分钟：日记情绪 → 期望情绪 → 本周小说要提供什么反转/补偿
- 如果现实正向，小说可写"压力+反思"来平衡
- 3 条链条验证：叙事永远在改写情绪走向，不是自然延续

### 加工深度

四阶段情绪加工流水线：
1. 1_片段：允许赤裸情绪素材
2. 2_脚本：给情绪找可行动的情节外壳
3. 3_初稿：让情绪在互动中具象化
4. 4_改稿：美学修饰 → 把负面炼成正向但真实的体验

愉悦度从 -0.20 跃至 +1.36。叙事距离不变（保持近战不疏离）。

### 节奏

小说是恒温器，不是急救针。平均愉悦度差距 +1.29 且不缩小——每周持续补偿，不是一次性治愈。

### 预警信号

如果现实很差但写不出暖的、甚至写更冷的，说明情绪算法过载，需人工干预而非硬写。

### 实验来源

1. 语义对齐：叙事与认知同域才有交集
2. 周内关联：日记与小说互补
3. 中介分析：叙事重塑情绪走向
4. 差距分析：理想始终高于现实
5. 加工深度：四阶段转化情绪
