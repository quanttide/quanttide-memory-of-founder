# 体裁

## 文章体裁（按表达方式和写作目的）

| 体裁 | 特征 | 用途 |
|------|------|------|
| 记叙文 | 记人、叙事、写景、状物，注重讲故事或描绘场景 | 叙述事件、描写人物/景物 |
| 说明文 | 以解释说明为主，客观地介绍事物特征、性质或原理 | 科普、说明书、教材 |
| 议论文 | 以论述为主，通过摆事实、讲道理表达观点和主张 | 评论、论文、社论 |
| 应用文 | 日常或工作中使用的具有特定格式的实用文体 | 书信、合同、通知、简历 |

## 文学体裁（文学作品的具体样式）

现代文学"四大体裁"：

| 体裁 | 特征 |
|------|------|
| 诗歌 | 高度集中地反映生活，包含丰富的感情和想象，分行排列，讲究节奏与韵律 |
| 散文 | 取材广泛、形式灵活，不拘泥于字数与格式，侧重抒发作者真情实感 |
| 小说 | 以塑造人物形象为中心，通过完整的故事情节和环境描写来反映社会生活 |
| 戏剧 | 供舞台演出使用，主要依靠台词和动作来推动剧情并塑造角色 |
