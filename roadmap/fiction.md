# 小说创作路线图

接下来的目标是铺开职场线。在现有感情线基础上，补充男女主各自的事业线场景——创业压力、团队管理、行业竞争。

元目标是建立描述现实状况和未来想象的叙事习惯。

## 当前缺口：11_x（世界扩张）

10_1（书房陪伴，关系顶点）与 12_2（客厅看剧）之间整段缺失。创作谈2 卡点："想深入扩展他们的世界，而不是只写两个人的互动"。

### 方案：11_x = 世界扩张三层（素材全在 2_脚本）

```
11_1 聚光灯下（事业圈）   ← 2_2_男主演讲素材
11_2 包子店早餐（未来圈）  ← 9_1_包子店素材
11_3 再坐便利店（原点回访）← 再坐便利店 + 偷看睡觉素材
```

| 章节 | 功能 | 情绪落点 | 呼应装置 |
| --- | --- | --- | --- |
| 11_1 聚光灯下 | 关系确认后第一次公开场合并肩（他是演讲者她是特邀嘉宾） | 全世界看到的是传说，她看到的是人（他演讲时暴露的脆弱只有她懂） | 代码梗（2_1）→ 演讲反击（"你先抄一遍就知道壁垒在哪里"） |
| 11_2 包子店早餐 | 从"我们"到"我们未来"（第一次共同想象家庭） | 在共同的想象中建立起对未来共同生活的期待 | 5_1 火锅的"家"意象 → 家的升级 |
| 11_3 再坐便利店 | 回访 4_1 起点（确定关系后复访） | 素材金句："走过这十年，看透了你的多面……这辈子有你真好" | 便利店=孤独起点 → 圆满终点（10_1 的 19 岁信落地） |

三层结构逻辑：11_1 向外（世界看到他们）→ 11_2 向未来（他们想象世界）→ 11_3 向内（回访原点确认圆满）。

破卡点关键：不需要新增群像人物——用已存在的世界（论坛/包子店/便利店）完成扩张；共同好友圈（8_2 已有）留给 12_x 之后。
