# 资产智能体

我的平台资产文件夹以树状结构组织。最高级是元仓库，下一级是三类单仓，示例、平台、库。各类库下也有明确的层级，比如平台包括的层级是文档、测试、代码、配置等等。

我现在的工作方式是模拟多智能体协作，每一级放一个，通过文件变化来触发智能体协作。

我的本地有 Opencode 可以直接用。我想写一个壳，让我能够看到我的实际协作关系。我目前的主要问题是理解多智能体的关系和分工。

文件管理属于数字资产管理，智能体结构设计属于智能体工程。

两个核心产出，主产品是资产维护系统，副产品是智能体关系系统。
